# Train 5 — REPL and Bytecode Disassembly

Train 5 adds interactive developer tooling without changing Emojineer's language semantics.

## Buffered REPL

Start an interactive session:

```text
emojineer repl
emojineer repl --cer cer/example.json
```

Source lines are accumulated into a session buffer so multiline functions, `🤔` blocks, and `🔁` loops can be entered naturally.

Commands:

- `:run` — compile and execute the current session.
- `:show` — print the current buffered source.
- `:explain` — run Explain Mode over the buffered source.
- `:clear` — clear the session.
- `:help` — show commands.
- `:quit` — exit.

Input consumed by `📥` is read from the same interactive input stream when `:run` executes.

## Bytecode disassembly

Compile source in memory and inspect the generated bytecode:

```text
emojineer dump examples/collections.emoji
```

Inspect an already-compiled bytecode file:

```text
emojineer disasm examples/collections.emjbc
```

The output shows the constant pool, function metadata, and every instruction with its bytecode offset, opcode, operand, and source line.

`disasm` verifies the loaded chunk before printing it.
